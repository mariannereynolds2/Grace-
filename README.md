# AG CORE Services website

Multi-page site for AG CORE Services: data, airtime, Cable TV and electricity orders through WhatsApp.

- `plans.js` holds the data plan prices (MTN, Airtel, Glo). Edit it to update prices.
- `assets/` holds the flyer images: `mtn-data-plans.jpg`, `airtel-data-plans.jpg`, `glo-data-plans-flyer.png`.
- WhatsApp orders go to +234 803 391 5483.

Static HTML, CSS and JavaScript. No build step: deploy the folder as-is on Vercel.
